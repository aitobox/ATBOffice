# Task: ATBOffice Phase 5 Parity & Stability Plan
## 第五期工程规划：工具栏细节、真实交互还原与稳定性治理

## Overview

基于 `.vibeoffice/` 当前检出版本、第四期规划及实际 Python 源码，对 Quire、Ledger、Lectern 的常用工作流重新建立可验证的行为基线，先解决崩溃和数据安全，再逐项还原工具栏及鼠标交互。配套差异与可拆分任务卡见 [`../clone/CLONE_DIFF.md`](../clone/CLONE_DIFF.md)。本文件是项目级实施计划，不代表已经修复或完成运行时全量审计。

- **状态**：规划；所有任务未开始。日期：2026-11-01。
- **优先级**：P0 崩溃、数据损坏及常用操作不可用；P1 工具栏及网格核心行为；P2 次要交互和视觉精修。
- **基线**：项目提交 `38664cabd0dcb88dabec91855eb0357dc30f0cdd`；原版 `.vibeoffice` 提交 `32ff53a5da0e75ebac11acdb0251cd3d8c7bf408`，执行时记录工作区状态、环境、语言、DPI 与截图条件。
- **范围**：三个编辑器、公共工具栏/命令系统、Ledger 网格和对象交互、文件生命周期及稳定性。此前高级功能不因第四期标记为完成而自动视为验收通过。

## Architecture

- **对照层**：原版 `public/{common,ledger,quire,lectern}/` 的声明、事件及 `.vibeoffice/docs/` 文档共同构成证据；桌面功能以实际平台差异注明。以稳定命令 ID、工具栏和上下文为索引构建逐控件清单。
- **命令层**：审查 `core/action_registry.py` 与 `ui/components/toolbar_buttons.py`，确保菜单项、主按钮、快捷键共享同一命令及启用/勾选状态；不强行把菜单标题当作动作 ID。
- **网格交互层**：`grid_viewport.py` 的命中测试、拖动会话、预览、提交与取消分离；所有终止路径清理计时器、鼠标捕获、预览及状态，原子执行数据变更并接入既有撤销机制；实现前确认实际模型接口。
- **稳定性层**：Python 异常、Qt 消息、原生崩溃和生命周期分别采集；带隐私约束的本地诊断信息不能包含文档内容或敏感路径；绝不依靠吞掉异常掩盖失败。
- **证据层**：每个问题记录原版位置、目标位置、复现、影响、测试和结论；原版与目标同窗口尺寸、DPI、缩放、语言、数据与状态下截图，记录测量误差，视觉工具仅作辅助。

## Implementation Plan

### Phase 5.0 — 可复现基线和崩溃分诊（P0，先行）

- [x] 固定两个仓库 SHA、Python/Qt/操作系统版本；分别运行现有测试和三模块启动、打开、编辑、保存、关闭冒烟，记录失败、退出码与超时，区分历史失败和新增回归。
- [x] 建立子进程 GUI 重放：窗口启动、切换标签、打开/关闭对话框、快速点击、选择对象/鼠标悬停、关闭窗口及事件循环排空；每个用例记录 stdout/stderr、`faulthandler`、退出码及平台崩溃报告路径。子进程隔离原生崩溃，设置超时，保留现场。
- [x] 对用户可复现问题记录最小操作序列与样本的脱敏方式；排查 QObject 生命周期、重复连接、Qt 虚方法遮蔽、跨线程 UI、异步回调、释放后访问，依据堆栈排序，不把猜测写成根因。
- [x] 对每个确认的 P0 崩溃先写失败回归，修复根因，再重复压力重放；保存、关闭、覆盖和失败注入检查原文件、临时文件、未保存状态及重开内容。

## Dependencies

- 既有 Python 3.12+、PySide6/Qt6、pytest、conda `ATBOffice`；当前平台优先 macOS，跨平台差异在可用平台验证并记录。
- 不引入新运行依赖，确有必要时先在实施任务中说明用途、许可及替代方案；Qt 原生事件/截图测试须在可用 GUI 会话运行，offscreen 结果不能替代原生验证。
- 复现用户特有崩溃可能需要具体操作、样本和系统崩溃报告；无证据时保持开放，不作为已解决项。
