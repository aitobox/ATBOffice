# Specification: Align Dual-Engine Canvas Viewports and Resolve 54 Incomparable Size Diffs

- **Issue**: #316
- **Branch**: `agent/issue-316-align-canvas-viewports-and-diffs`
- **Component**: Office Diff Tooling (`scripts/office_diff/`, `docs/clone/`)
- **Status**: Approved (Autonomous >= 90% confidence)

## 1. Overview & Problem Statement

In the automated visual rendering audit (`docs/clone/OFFICE_DOCS_DIFF.md` generated by commit `3e9bffa`), 54 out of 73 core supported OOXML documents were reported as `INCOMPARABLE_SIZE` (dimension mismatch between Chromium CDP captures like 1178x798, 982x745, and 1178x767 vs. PySide6 offscreen captures like 1440x784, 1440x744, and 1440x773). This prevented objective similarity calculation across 74% of the corpus.

The root causes are twofold:
1. **CDP Viewport Clipping**: In `capture_doc_vibeoffice.mjs`, Chromium CDP captures the inner canvas (`.center` / `.work` / `.main`), which excludes the 262px right taskpane in Quire and Ledger, and excludes both the 196px leftpane and 262px rightpane in Lectern, yielding canvas rects of 1178x767 (Word), 1178x798 (Excel), and 982x745 (PowerPoint).
2. **PySide6 Offscreen Capture Target & Fallback**: In `scripts/office_diff/capture.py`, offscreen captures default to grabbing the entire `centralWidget()` at full window width (1440px), and for Excel it checked `window.spreadsheet_view.table_view` (which does not exist; the actual view is `grid.viewport()`). Furthermore, even when grabbing viewports, the grabbed pixmap dimensions were not constrained or aligned to the reference CDP canvas rects.

## 2. Technical Architecture & Design

### 2.1 CDP Canvas Viewport Rects Definition
Define standard reference CDP canvas dimensions in `scripts/office_diff/capture.py`:
```python
CDP_CANVAS_RECTS: dict[str, tuple[int, int]] = {
    "excel": (1178, 798),
    "powerpoint": (982, 745),
    "word": (1178, 767),
}
```

### 2.2 PySide6 Canvas Viewport Boundary Isolation
Accurately resolve the inner document canvas viewport for each module:
- **Word (`Quire`)**:
  ```python
  cv = getattr(window.writer_view, "canvas_view", None)
  grab_target = cv.viewport() if (cv and hasattr(cv, "viewport")) else window.writer_view
  ```
- **Excel (`Ledger`)**:
  ```python
  grid = getattr(window.spreadsheet_view, "grid", None) or getattr(window.spreadsheet_view, "grid_viewport", None)
  grab_target = grid.viewport() if (grid and hasattr(grid, "viewport")) else window.spreadsheet_view
  ```
- **PowerPoint (`Lectern`)**:
  ```python
  ws = getattr(window.presentation_view, "workspace", None)
  grab_target = ws.canvas_view.viewport() if (ws and hasattr(ws, "canvas_view") and hasattr(ws.canvas_view, "viewport")) else window.presentation_view
  ```

### 2.3 Viewport Alignment and Clipping Bounding Box
Introduce `align_pixmap_to_canvas(pixmap: QPixmap, target_size: tuple[int, int]) -> QPixmap`:
- Looks up target dimensions from the corresponding baseline PNG in `baseline_dir` if available, or falls back to `CDP_CANVAS_RECTS[app]`.
- If the grabbed pixmap already matches `target_size`, return as-is.
- If dimensions differ, create a target `QPixmap(target_w, target_h)` initialized with canvas background (`Qt.GlobalColor.white`), and paint the captured content starting from `(0, 0)` with dimension bounds `(min(w, target_w), min(h, target_h))`.
- This ensures deterministic dimension parity with the CDP baseline across all 73 core documents.

### 2.4 Aligning Existing Candidate Screenshots & Report Generation
- Align the existing candidate images in `screenshots/office_audit_20261106/atboffice` to match baseline dimensions.
- Re-run `scripts/run_office_diff.py --all` to recompute all similarity metrics, eliminating all 54 `INCOMPARABLE_SIZE` errors.
